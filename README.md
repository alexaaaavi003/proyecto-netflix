# Netflix - Proyecto Final

## Descripción del Proyecto
Aplicación web funcional inspirada en Netflix. Permite la gestión de usuarios mediante una base de datos relacional (Registro, Login y sistema CRUD administrativo) y muestra un catálogo interactivo de películas. 

## Que utilizamos?
- HTML5 y CSS3 para el diseño y la interfaz.
- JavaScript para la interactividad (buscador y sinopsis).
- PHP para la lógica de backend y conexión a la base.
- MySQL para la base de datos relacional.
